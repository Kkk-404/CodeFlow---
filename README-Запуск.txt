Codeflow Desktop — Windows, офлайн

По умолчанию `start_codeflow.bat` запускает отдельное окно настольной версии. Обычный браузер и веб-сервер не запускаются. Для работы приложения интернет не нужен; учебные данные уже лежат рядом с программой.

Запуск
1. Полностью распакуй архив `Codeflow-Windows.zip` в папку. Не запускай BAT прямо из окна ZIP.
2. Если Python 3 с Tkinter уже установлен, запусти `start_codeflow.bat` — интернет не нужен.
3. Чтобы установить ярлык и файлы в `%LOCALAPPDATA%\Codeflow`, запусти `install_codeflow.bat`. Установщик проверит Python/Tkinter и создаст ярлык. Если Python не установлен, для его первой установки через WinGet может понадобиться интернет.
4. Прогресс хранится локально в `%LOCALAPPDATA%\Codeflow\desktop-progress.json`; его можно экспортировать и импортировать через раздел «Прогресс».

Что есть в настольной версии
- 9 курсов, 288 уроков, вопросы для самопроверки и проверка решений по критериям.
- Справочник из 231 карточки с примерами, местами применения и типичными ошибками.
- Тренировка, сохранение черновиков и прогресса, JSON-резервная копия.
- Данные находятся в комплекте: для чтения уроков, проверки заданий и справочника подключение к сети не требуется.
- Python-код можно запустить локально из урока Python. Это не песочница: код получает права текущего пользователя, поэтому запускай только то, чему доверяешь. Сам Codeflow не исполняет код автоматически.
- ИИ-тьютор в Windows-сборке отключён.
- Это отдельная компактная настольная версия: расширенные лекции, заметки/закладки, переключение тем, PWA и Pyodide-runner остаются в веб-версии.

Дополнительно: веб-версия
`start_codeflow-web.bat` запускает прежнюю веб-версию через локальный Python-сервер и открывает браузер. Используй её, если нужны браузерные функции, включая локальный Pyodide runner и установку PWA. Веб-файлы и runtime тоже лежат в этом архиве; для работы на localhost интернет не требуется.

Файлы комплекта
- Настольный запуск: `start_codeflow.bat`, `Codeflow-Desktop.py`, `desktop-course-data.json`, `desktop-reference-data.json`.
- Веб-запуск: `start_codeflow-web.bat`, `index.html`, `app.js`, `reference.html`, `reference.js`, `manifest.json`, `service-worker.js`, `python-runner-worker.js`, `codeflow_server.py`.
- Остальные общие ресурсы: `codeflow.ico`, `assets/`, `icons/`, `pyodide/`, `_headers`, `third-party-notices.txt`.
- Только Windows: `install_codeflow.bat`.

iPhone / iPad через HTTPS PWA
Для iOS используй статические веб-файлы из этого комплекта (`index.html`, `app.js`, `reference.html`, `reference.js`, `assets/`, `manifest.json`, `service-worker.js`, `python-runner-worker.js`, `_headers`, `codeflow.ico`, `icons/`, `pyodide/`) и HTTPS-хостинг. Хостинг должен применить CSP-заголовки из `_headers`. Настольная версия и ИИ-тьютор на iOS не работают; не публикуй локальный сервер как AI API.
