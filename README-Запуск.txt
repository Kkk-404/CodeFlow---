Codeflow — установка и запуск на Windows

Установка:
1. Распакуй весь архив в отдельную папку.
2. Запусти install_codeflow.bat.
3. Установщик скопирует сайт в %LOCALAPPDATA%\Codeflow и создаст ярлык Codeflow на рабочем столе.
4. Если рабочий Python 3 доступен как `py -3`, `py -V:3.14`, `python` или `python3`, установщик воспользуется им. Если Python не найден, он предложит установить официальный Python Install Manager и runtime Python 3.14 через WinGet. Установка Python начнётся только после твоего подтверждения.
5. При запуске страницы откроется браузер: http://127.0.0.1:8765/index.html.

Если WinGet недоступен, установщик откроет официальную страницу Python. Установи Python 3 и повторно запусти install_codeflow.bat. Для автоматической установки требуется подключение к интернету.

После установки сайт можно запускать ярлыком Codeflow или файлом start_codeflow.bat в %LOCALAPPDATA%\Codeflow. Сервер привязан только к 127.0.0.1 и доступен на этом компьютере. Чтобы остановить его, закрой свёрнутое окно «Codeflow — локальный сервер».

Если порт 8765 занят, батник сообщит об этом; измени PORT=8765 в начале start_codeflow.bat на другой свободный порт. Не распаковывай приложение рядом с секретными файлами: локальный Python-сервер отдаёт содержимое папки установки.
