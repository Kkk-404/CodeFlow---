# CodeFlow---
Данное приложение создано для изучения языков программирования или же его повторения. Приложение не гарантирует 100% понимания языка(-ов) который вы выбрали, моя программа всего лишь дает вам материал для повторяи или изучения языка.
Для установки данной программы просьба ознакомится со всеми файлами, найдите файл под именем install_codeflow.bat
После установки запустите файл start_codeflow.bat для запуска самой программы
