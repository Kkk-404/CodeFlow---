## 🚀 Быстрый старт

1. Скачай или клонируй комплект и **распакуй его полностью** в отдельную папку. Не запускай BAT-файлы из окна ZIP.
2. Для Desktop нужен **Python 3 с Tkinter**. Если Python уже установлен, переходи к следующему шагу.
3. Запусти `start_codeflow.bat` двойным щелчком — откроется отдельное окно Codeflow.

### Какой BAT-файл выбрать?

| Файл | Когда использовать | Что произойдёт |
|:--|:--|:--|
| `start_codeflow.bat` | Обычный запуск | Откроет нативное окно Codeflow Desktop без браузера. |
| `install_codeflow.bat` | Первая установка или обновление | Скопирует комплект в `%LOCALAPPDATA%\Codeflow`, при необходимости предложит установить Python 3.14 через WinGet, создаст ярлык и запустит Desktop. |
| `start_codeflow-web.bat` | Нужны расширенные браузерные функции или PWA | Поднимет локальный сервер на `127.0.0.1:8765` и откроет веб-версию в браузере. |

**Если Python не установлен:** установщик может загрузить официальный Python Install Manager и Python 3.14 через WinGet. Для этой первоначальной загрузки понадобится интернет. Сами уроки и локальные материалы не требуют подключения.

> **Важно:** храни BAT-файлы рядом с остальными файлами комплекта. Не перемещай отдельный `.bat` в другую папку и не смешивай Windows-файлы с комплектом другой ОС.

## ✨ Что есть в Codeflow

### Codeflow Desktop

- Каталог курсов и 288 уроков с задачами, подсказками и вопросами для самопроверки.
- Справочник из 231 карточки по командам и конструкциям.
- Практика, проверка решений, очки опыта и локальные черновики.
- Запуск Python из урока — только по нажатию пользователя.
- Переключатель **RU / EN**; выбранный язык сохраняется на этом компьютере.
- Самостоятельное окно Windows: обычный браузер для рекомендуемого запуска не нужен.

### Веб-версия и PWA

В веб-версии доступны браузерные разделы, которых нет в компактном Desktop: библиотека лекций, диагностика, заметки и закладки, тест-планы, проекты, повторение, достижения, темы оформления и учебный терминал-песочница. Python запускается через локальный Pyodide runtime в браузере.

Оба варианта включают русские материалы и английский перевод. При первом успешном посещении PWA сохраняет оболочку и локальные ресурсы для дальнейшей работы офлайн.

## 🌐 Переключатель RU / EN

- Меняет язык интерфейса и учебных материалов в **Desktop** и **веб/PWA**.
- Переводы входят в комплект: во время занятий приложение не загружает их из сети.
- **Английский — автоматический черновик OPUS-MT, а не редакторски вычитанный перевод.** Проверяй термины, формулировки и технические нюансы.
- Исходные кодовые примеры, критерии проверки и некоторые текстовые литералы сохраняются, чтобы задания продолжали соответствовать встроенным проверкам.
- `en-translation-report.json` содержит сводку и примеры. В текущей сборке отчёт отмечает **325 значений перевода с кириллицей**; многие из них — сохранённый код или ожидаемый текст вывода, но возможные остатки в обычной прозе тоже требуют проверки.
- Уведомление о машинном черновике показывается при выбранном английском языке.

Файлы переводов лицензированы и атрибутированы в [`third-party-notices.txt`](third-party-notices.txt). В комплект включены готовые строки перевода, а не сама модель; модель не запускается и не скачивается во время занятий.

## 🖥️ Веб-версия и установка PWA

На Windows запусти `start_codeflow-web.bat`. Он использует локальный Python-сервер и открывает браузер. Для локальных уроков и Pyodide интернет не требуется.

Для установки PWA на iPhone или iPad размести статические веб-файлы на **HTTPS-хостинге** и примени CSP-заголовки из `_headers`. После первой загрузки браузер сможет использовать закэшированные ресурсы офлайн. Настольное приложение Windows на iOS не запускается.

### Необязательный локальный ИИ-тьютор

Веб-сервер может обращаться к **отдельно установленной локальной Ollama** и локальной модели. Если Ollama не настроена, обычные курсы и справочник продолжают работать. ИИ-тьютор **отключён в Codeflow Desktop**.

Сервер Codeflow по умолчанию привязан только к `127.0.0.1` и проверяет локальные запросы. **Не меняй привязку на сетевой адрес и не публикуй локальный Ollama/API наружу.** Не добавляй в комплект API-ключи: облачные AI API этой сборке не нужны.

## 🔐 Безопасность и приватность

- **Desktop Python — не песочница.** Код выполняется с правами текущей учётной записи Windows и может обращаться к файлам и сети. Запускай только код, которому доверяешь.
- Веб-версия использует локальный Pyodide в браузерном Web Worker. Это учебный раннер, а не гарантия безопасного запуска враждебного кода.
- Прогресс не отправляется в аккаунт или облако: он остаётся в локальном файле Desktop или в профиле браузера.
- Между Desktop и веб-версией нет автоматической синхронизации. Для переноса используй экспорт/импорт в соответствующей версии; форматы сохранений могут различаться.

## 💾 Где находятся данные

Настольный прогресс хранится в:

```text
%LOCALAPPDATA%\Codeflow\desktop-progress.json
```

Веб-прогресс сохраняется локально в хранилище текущего браузера. Очистка данных сайта может удалить его — заранее экспортируй резервную копию. Учебные данные курсов и справочника хранятся рядом с приложением в комплекте.
