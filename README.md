## 🚀 Быстрый старт

1. Склонируй репозиторий или полностью распакуй комплект в отдельную папку. **Не запускай BAT-файлы прямо из окна ZIP.**
2. Убедись, что установлен **Python 3 с Tkinter**.
3. Дважды щёлкни **`start_codeflow.bat`**. Откроется настольная версия Codeflow.

### Способы запуска

| Файл | Действие |
|:--|:--|
| `start_codeflow.bat` | Запускает нативное окно Codeflow Desktop. Это рекомендуемый вариант. |
| `install_codeflow.bat` | Проверяет Python/Tkinter, устанавливает комплект в `%LOCALAPPDATA%\Codeflow` и создаёт ярлык. Если Python отсутствует, его первая установка через WinGet может потребовать интернет. |
| `start_codeflow-web.bat` | Запускает веб-версию через локальный Python-сервер и открывает её в браузере. |

> **Нужен Python?** Для настольного запуска требуется Python 3 с Tkinter. Если он ещё не установлен, установи его и запусти BAT-файл снова. Интернет может понадобиться только для первой установки Python.

## ✨ Что внутри

- **Курсы:** девять языков и инструментов, 288 уроков, задания и вопросы для самопроверки.
- **Справочник:** 231 карточка с синтаксисом, примерами, применением и типичными ошибками.
- **Тренировка:** короткие вопросы по материалам курсов.
- **Локальный прогресс:** выполненные уроки, ответы и черновики сохраняются на устройстве.
- **Резервная копия:** экспорт и импорт прогресса в JSON из раздела «Прогресс».
- **Запуск Python:** можно выполнить код прямо из урока Python.

### ⚠️ Важно о запуске кода

Код запускается на компьютере с правами текущего пользователя. **Это не песочница:** программа может обращаться к файлам и сети. Запускай только код, которому доверяешь. Codeflow не запускает ученические решения автоматически.

ИИ-тьютор в Windows-версии отключён.

## 💾 Прогресс и файлы

Прогресс настольной версии хранится здесь:

```text
%LOCALAPPDATA%\Codeflow\desktop-progress.json
```

Перенеси его между компьютерами с помощью JSON-экспорта и импорта в приложении. Папки `desktop-course-data.json` и `desktop-reference-data.json` должны оставаться рядом с программой — в них находятся локальные материалы курсов и справочника.

### Основные файлы комплекта

- `Codeflow-Desktop.py` — настольное приложение на Tkinter.
- `desktop-course-data.json`, `desktop-reference-data.json` — данные уроков и справочника.
- `start_codeflow.bat`, `install_codeflow.bat` — запуск и установка для Windows.
- `start_codeflow-web.bat`, `index.html`, `app.js`, `reference.html`, `reference.js` — веб-версия.
- `codeflow_server.py`, `python-runner-worker.js`, `pyodide/` — локальный веб-сервер и браузерный Python runtime.
- `assets/`, `icons/`, `codeflow.ico` — локальные изображения и иконки.

Сохраняй комплект целиком: не выноси BAT-файл отдельно от остальных файлов.

---

## 🌐 Веб-версия и PWA

Если нужны браузерные функции, запусти `start_codeflow-web.bat`. Веб-приложение и Python runtime находятся в комплекте; на `localhost` интернет для их работы не требуется.

Для установки веб-версии как PWA на iPhone или iPad размести статические файлы на HTTPS-хостинге. Хостинг должен применять CSP-заголовки из `_headers`. Настольная версия для iOS не подходит; локальный сервер не публикуй как сетевой AI API.
